Caveats

  • Scope is intentionally small: four breweries in Bend, Oregon.
  • Coordinates are a mix of exact map-link values and one approximate geocode for Bend Brewing Co.
  • Website and address fields were normalized from public directory pages and brewery sites; phone numbers were not consistently available in the sources used here.
  • Freshness is limited to the public pages consulted during this run, so closures, relocations, or rebrands after the source pages were published may not be reflected.
  • Map-ready CSV is suitable for a simple static map layer, not for routing or delivery accuracy.

Source Notes

Public sources consulted during this run included Open Brewery DB city and brewery pages, brewery official sites, a public property listing for Worthy Brewing Company, and public map links opened from the brewery pages. The Bend Brewing Co coordinate is approximate and explicitly marked as such in the data files.
